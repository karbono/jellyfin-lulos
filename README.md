# jellyfin-lulos

Compilación automática en GitHub Actions de [Jellyfin Android](https://github.com/jellyfin/jellyfin-android) (variante `proprietary` con Chromecast) preconfigurada con `https://jelly.lulospi.party`.

Al abrir la app por primera vez, conecta directamente al servidor y solo pide usuario y contraseña.

## Descarga

- Página web: `https://dl.lulospi.party/jellyfin`
- Enlace directo APK: `https://dl.lulospi.party/jellyfin/apk`
